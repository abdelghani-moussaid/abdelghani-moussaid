### 🚀 Featured Project: ZatcaOracle v2.0 - High-Performance QR Engine

A .NET 10 Native AOT microservice specifically engineered for ZATCA Phase 2 compliance[cite: 1]. It is designed to act as a drop-in, high-throughput cryptographic bridge for high-concurrency environments.

*   **Ultra-Low Latency:** Achieves sub-millisecond execution (P99 < 1ms)[cite: 1]. Live production benchmarks demonstrate 0.76ms internal compute via Native AOT[cite: 1]. Scales to 3,300+ TPS using --cpu-boost optimized orchestration[cite: 1].
*   **Infrastructure & Security:** Built on a Distroless Chiseled architecture[cite: 1]. Cryptographic primitives are executed in a Zero-Shell environment, ensuring public key materials process in a secure, isolated memory space[cite: 1].
*   **Strict Compliance:** Guarantees 100% Saudi Data Residency by deploying directly in me-central2 (Dammam)[cite: 1].
*   **Optimized API Strategy:** Features a "Magic Path" (1ms execution) that auto-extracts cryptographic materials for frictionless onboarding[cite: 1]. Production workflows utilize a cached "Pro Path" (0.78ms execution) to achieve maximum throughput[cite: 1].
*   **Developer & AI Ready:** Available on RapidAPI[cite: 1]. ZatcaOracle is fully MCP-native, allowing seamless configuration as a tool directly inside IDEs like Cursor and Claude[cite: 1].
